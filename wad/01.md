
# 📋 دليل لوحة التحكم - Admin Dashboard

> دليل شامل لجميع أزرار ووظائف لوحة التحكم في نظام توزيع الأدوية الذكي

---

## 🎛️ الأزرار السريعة (Quick Actions)

### 1️⃣ زر "تحميل الدواء صندوق 2"

- **الوظيفة:** `loadMode()`
- **API:** `POST /load_mode`
- **الشرح:** يحرك الصندوق الدوار إلى وضعية التحميل (100°) لتعبئة الدواء في الصندوق 2
- **الاستخدام:** اضغط الزر → عبّي الدواء → اضغط زر "صندوق 1" للعودة

---

### 2️⃣ زر "تحميل الدواء صندوق 1"

- **الوظيفة:** `goZero()`
- **API:** `POST /go_zero`
- **الشرح:** يحرك الصندوق الدوار إلى الوضع الصفري (0°) لتعبئة الدواء في الصندوق 1
- **الاستخدام:** العودة للوضع الافتراضي (Home Position)

---

### 3️⃣ زر "تشغيل الروبوت" / "إيقاف الروبوت"

- **الوظيفة:** `toggleRobot()`
- **API:**
  - `POST /robot/start` (للتشغيل)
  - `POST /robot/stop` (للإيقاف)
- **الشرح:** يشغل أو يوقف حركة الروبوت (المحركات)
- **المظهر:** يتغير لون الزر من أخضر (تشغيل) لأحمر (إيقاف)

---

### 4️⃣ زر "طوارئ" (Emergency)

- **الوظيفة:** `emergencyStop()`
- **API:** `POST /robot/stop`
- **الشرح:** إيقاف فوري لجميع الحركات في حالة الطوارئ
- **⚠️ تحذير:** استخدمه فقط في حالات الطوارئ

---

### 5️⃣ زر "إعادة تشغيل النظام"

- **الوظيفة:** `systemRestart()`
- **API:** `POST /api/system/restart`
- **الشرح:** يعيد تشغيل تطبيق Flask بالكامل وينظف الكاش (Cache)
- **الوقت المتوقع:** 10 ثواني

## 📦 بطاقات الصناديق (Schedule Cards)

### 6️⃣ زر "🔓" (فتح الصندوق)

- **الوظيفة:** `openBox(boxId)`
- **API:** `POST /open_box`
- **البيانات المرسلة:**
  ```json
  {
    "box": boxId  // رقم الصندوق (1 أو 2)
  }
  ```

#### 🔄 **التدفق الكامل للعملية:**

##### **المرحلة 1️⃣: التحقق من الصلاحيات**
```
1. فحص إعداد "auth_enabled" من قاعدة البيانات
   
   📌 إذا كان مُفعّل:
      ✅ التحقق من State Machine
      ✅ يجب أن تكون الحالة = VERIFIED
      ❌ إذا لم يتم التحقق → رفض الصرف (HTTP 403)
      
   📌 إذا كان مُعطّل:
      ✅ السماح بالصرف المباشر
      ⚠️ تخطي التحقق من الوجه
```

##### **المرحلة 2️⃣: فحص المخزون**
```
1. قراءة جدول الصندوق من قاعدة البيانات
2. استخراج:
   - stock_count: المخزون الحالي
   - dose_per_dispense: عدد الحبوب لكل جرعة
   
3. التحقق:
   if (stock < dose):
      ❌ رفض الصرف
      return {"error": "low_stock"}
   else:
      ✅ متابعة العملية
```

##### **المرحلة 3️⃣: تنفيذ عملية الصرف**
```
State Machine → تغيير الحالة إلى DISPENSING

┌─────────────────────────────────────────┐
│  1. تشغيل الصوت (SOUND_EMERGENCY)     │
│  2. استدعاء: dispense_dose(box)       │
│     ├─ تدوير الكاروسيل للصندوق المطلوب│
│     ├─ فتح البوابة (80°)              │
│     ├─ انتظار 1 ثانية (سقوط الدواء)  │
│     ├─ إغلاق البوابة (0°)             │
│     └─ تسجيل العملية في قاعدة البيانات│
└─────────────────────────────────────────┘
```

##### **المرحلة 4️⃣: تحديث المخزون**
```
1. حساب المخزون الجديد:
   new_stock = stock_count - dose_per_dispense
   
2. حفظ في قاعدة البيانات:
   save_schedule(
     box_id: box,
     stock_count: new_stock,
     ... (باقي البيانات)
   )
   
3. فحص الحد الأدنى:
   if (new_stock < low_stock_threshold):
      ⚠️ إظهار تحذير
      📦 عرض رابط الصيدلية
```

##### **المرحلة 5️⃣: العودة للوضع الآمن (Home Position)**
```
⏱️ انتظار 2 ثانية (التأكد من إغلاق الباب)
🏠 go_home_zero() → إرجاع الكاروسيل للصندوق 1 (0°)

🛡️ هذا مهم لـ:
   - حماية الميكانيكا من الكسر
   - وضع محدد ومعروف دائماً
   - جاهزية الصندوق 1 للاستخدام
```

##### **المرحلة 6️⃣: الاستجابة النهائية**
```json
✅ نجاح:
{
  "status": "✓ تم صرف جرعة من الصندوق X",
  "warning_message": "تنبيه: المخزون منخفض (5 قرص)!",  // اختياري
  "pharmacy_url": "https://kuludonline.com/"              // اختياري
}

❌ فشل - مخزون منخفض:
{
  "status": "✗ عذراً، المخزون غير كافٍ للصرف!",
  "error": "low_stock"
}
// HTTP Status: 400

❌ فشل - عدم التحقق:
{
  "status": "⛔ رفض الصرف: يرجى التحقق من الوجه أولاً",
  "error": "auth_failed",
  "can_confirm": false
}
// HTTP Status: 403
```

#### 🚫 **القيود والشروط:**

| القيد | التفاصيل |
|------|----------|
| **التعرف على الوجه** | إذا مُفعّل، يجب التحقق قبل الصرف (State = VERIFIED) |
| **المخزون** | يجب أن يكون: `stock_count >= dose_per_dispense` |
| **رقم الصندوق** | فقط 1 أو 2 (حسب BOX_CONFIG في hardware.py) |
| **تزامن العمليات** | لا يمكن فتح صندوقين في نفس الوقت (State Machine) |
| **وقت الانتظار** | 2 ثانية بعد الإغلاق قبل تحريك الكاروسيل |
| **GPIO** | يعمل فقط على Raspberry Pi (أو وضع المحاكاة على الكمبيوتر) |

#### ⚙️ **الإعدادات المؤثرة:**

```python
# من database (schedules table):
- hour, minute         # وقت الجرعة التلقائية
- enabled              # تفعيل/تعطيل الجدولة
- medicine_name        # اسم الدواء
- stock_count          # المخزون الحالي ⚠️
- dose_per_dispense    # عدد الحبوب لكل صرف ⚠️
- low_stock_threshold  # حد التنبيه ⚠️
- pharmacy_url         # رابط الشراء

# من database (settings table):
- auth_enabled         # تفعيل نظام الوجه ⚠️

# من hardware.py:
- BOX_CONFIG[box]['pin']         # منفذ GPIO
- BOX_CONFIG[box]['open_angle']  # 80°
- BOX_CONFIG[box]['close_angle'] # 0°
- BOX_ANGLES[box]                # زاوية الكاروسيل
- DISPENSE_HOLD_TIME             # 1 ثانية
```

#### 📊 **مثال عملي:**

```javascript
// في الواجهة:
openBox(2)

// يرسل:
POST /open_box
{
  "box": 2
}

// السيرفر يتحقق:
✅ auth_enabled = false → تخطي التحقق
✅ stock = 20, dose = 2 → كافي

// ينفذ:
🔊 صوت التنبيه
🔄 تدوير الكاروسيل → 143° (صندوق 2)
🚪 فتح الباب → 80°
⏱️ انتظار ثانية
🚪 إغلاق الباب → 0°
💾 تحديث المخزون → 18

// ينتظر:
⏱️ 2 ثانية

// يعود:
🏠 تدوير الكاروسيل → 0° (صندوق 1)

// يرد:
{
  "status": "✓ تم صرف جرعة من الصندوق 2"
}
```

#### 🔍 **ملاحظات إضافية:**

1. **Thread Safety:** العملية محمية بـ State Machine (لا تداخل)
2. **Error Recovery:** إذا حدث خطأ، يحاول إغلاق الباب للسلامة
3. **Logging:** كل عملية تُسجل في `dose_logs` table
4. **Audit Trail:** تسجيل في `audit_log` (إذا مُفعّل)
5. **الصوت:** `SOUND_EMERGENCY` يشغل قبل الصرف كتنبيه

## 🏠 ميزة Home Position الجديدة

### السلوك الافتراضي:
- ✅ عند بدء النظام → الصندوق 1 في الأمام
- ✅ بعد فتح أي صندوق → العودة للصندوق 1 (مع انتظار 2 ثانية للأمان)
- ✅ بعد التحميل → يدوي (اضغط زر "صندوق 1" بعد التعبئة)

### الفوائد:
- 🛡️ حماية ميكانيكية (عدم الحركة أثناء فتح الأبواب)
- 📍 وضع معروف ومحدد دائماً
- 🔧 سهولة الصيانة والتشغيل
